# Changelog

All notable changes to both packages are recorded in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). The Python and TypeScript packages share their version.

## [0.1.0] - 2026-11-26

### Added

- Comparison of values by key (numbers by value, yes/no without case), named colours for groups, checking of groups
  and legend headings with codes and messages, carry-over to new data, classes, legend rows and a MapLibre GL style
  expression, in Python and TypeScript with the same names.
- Phrases for an activity log of what changed in the groups (Python).
- The shared test cases `spec/vectors.json`, run by both packages.
